# Barcelona Topic List – Carlos Tour

Stand 7. November 2026

## How to use this list

Every Barcelona POI script is tagged against these topic IDs, so the app's told-once registry knows what the user has already heard.

- **Introduces:** topics this script explains in full when they haven't been told yet. It must also have a callback version.
- **Calls back:** topics it only references in 1–2 sentences, and only if they've already been told.
- **Needs:** topics the script can't make sense without. If a needed topic hasn't been told, the app plays a short primer first.

**What counts as a topic:** something that comes up at two or more POIs, or that the listener needs in order to understand several stops. Facts that belong to a single POI stay in that POI's script and don't go on this list.

**Flag column:** **S** = sensitive, so the filter rules in the last section apply to the script and to the Q&A on that topic. **V** = verify: a date or current status that changes over time and must be checked before recording.

**IDs** are stable. Don't renumber them; add new ones at the end of a category.

## Sensitive-topic filter (S flag)

The guide explains, attributes and stays neutral. On settled history it states the facts plainly; on today's contested questions it presents the main positions and never chooses between them.

**In the scripts**

1. **Describe, don't judge.** Say what happened and who believed what ("supporters argued…, opponents argued…"). The guide persona never gives its own view on independence, the monarchy, parties or Spain–Catalonia relations.
2. **Settled facts are not "two sides".** The 1714 siege, the execution of Companys and the bombing of civilians are told plainly. Balance applies to interpretations and to today's debates, not to whether these events happened.
3. **Contested topics get both views in one or two sentences**, then the script moves on. This applies to POL-04 to POL-07, EMD-11, ANT-14 and GEO-09.
4. **No current politics in recorded audio.** Anything that can change (court cases, the amnesty, governments, tourism rules) stays out of the pre-recorded scripts and is left to the Q&A, where it can carry an "as of" caveat.
5. **Violence without graphic detail.** Respect for victims. GEO-10 (the 2017 attack) is only mentioned at the memorial, in one sentence, if at all.
6. **Language.** Catalan place names first, the Spanish name where it helps. Never call Catalan a dialect.
7. **Two-person sign-off.** Every S-flagged script gets a second reviewer from your team before recording.

**In the Q&A (system-prompt rules)**

- **Balance.** For S-flagged topics, set out the main positions and attribute each to whoever holds it. Make no recommendations and give no party or voting guidance.
- **When pressed for an opinion,** the guide declines in character, for example: "I'm a guide, not a politician. Locals disagree passionately; here's how each side sees it."
- **Recent events.** Say the information may be out of date, and don't speculate about ongoing legal or political outcomes.
- **Safety notes** stay separate and short: one line per area, e.g. "Heads up, pickpockets are common here."
